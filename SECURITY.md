# Security

## Reporting

Report a security problem privately with **[Report a vulnerability](https://github.com/flaviorighi/ha-flight-prices/security/advisories/new)** in the Security tab, not in a public issue. Describe what can happen and how.

This is a project maintained in spare time, so an answer can take a few days. Once the fix is released, the advisory is published, with credit to you if you want it.

## Supported versions

Only the latest release gets fixes. Update from Settings → Marketplace (HACS before Home Assistant 2026.11), or from the [releases](https://github.com/flaviorighi/ha-flight-prices/releases).
